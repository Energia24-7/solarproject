# Solar Plant Explorer V3

Interfaz visual tipo 3D/isométrica para una planta solar de 1 MW, pensada como herramienta comercial Prysmian/Cablec.

## Estructura
- `index.html` interfaz
- `css/style.css` diseño y animaciones
- `js/app.js` interacción
- `data/products.json` catálogo editable
- `assets/images/` imágenes futuras
- `assets/docs/` fichas PDF futuras

## GitHub Pages
Sube toda la carpeta al repositorio y activa Settings → Pages → Deploy from branch → main → root.

No requiere servidor ni API de pago. La siguiente evolución puede incorporar productos reales, fichas técnicas, selector 1/5/10 MW, BOM y enlaces de WhatsApp/CRM.
